## Merge & rebase
### __Prompt__: *Explain the practical difference between merge and rebase using an example from my own repo.*
Both commands bring another branch's work into one, the difference is how they record it in the history.
Merge should be used always while working on collaborative teams, since the history must be mainted, Rebase should be only used while working in private/individually as a way to "clean" the history before push our changes into main, this way will be easy to maintan and review if some problem arise.
