# Anchor App: Automation Exercise

- UI: https://automationexercise.com
- API docs: https://automationexercise.com/api_list

## Why this app
Chosen because it allows covering UI (Playwright) and API (Postman/Newman)
with a single application, giving end-to-end coherence to the final framework.

## UI flows covered in this repo
- [ ] User registration
- [ ] Login / Logout
- [ ] Product search and filtering
- [ ] Add to cart
- [ ] Checkout

## API endpoints covered in this repo
- [ ] GET products
- [ ] GET brands
- [ ] POST login
- [ ] POST register
- [ ] PUT update account
